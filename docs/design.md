## 1. 整體架構

```
iPhone（加到主畫面的網頁 App）
 ├── 畫面：HTML + CSS
 ├── 邏輯：JavaScript
 ├── 資料：存在手機瀏覽器裡（localStorage）
 └── 需要 AI 時 ──► Groq API（主力）──失敗時──► Gemini API（備援）
```

- **沒有自己的伺服器**：網頁放在 **GitHub Pages**（免費、有 https）。iPhone 要有 https 才能用麥克風，也才能加到主畫面
- **API 金鑰**：第一次打開時在「設定」貼上，只存在手機裡，不會出現在程式碼和網路上

## 2. 檔案結構

```
my-diary/
├── index.html      畫面骨架
├── style.css       外觀（顏色、字體、泡泡樣式）
├── app.js          主要邏輯（送出、顯示、切換日期、提醒）
├── storage.js      存取資料
├── ai.js           跟 AI 溝通：Groq 主力、Gemini 備援（之後換 AI 只改這個）
├── theo.js         Theo 的個性設定和說話方式  ← 很適合你來寫
├── goals.js        目標：找出目標、提醒、目標頁
├── reviews.js      每週／每月回顧
├── calendar.js     日曆頁（含回顧）
├── manifest.json   讓網頁可以加到主畫面
├── icon.png        主畫面上的 App 圖示
└── docs/           規格文件
```

## 3. 畫面

### 3.1 聊天頁（主畫面）

```
┌─────────────────────────┐
│ ‹ 10/8（四）今天 ›  🎯 ⚙️ │  ← 左右切換日期；🎯 目標；⚙️ 設定
├─────────────────────────┤
│ 🔔 Theo：欸，明天下午     │  ← 提醒（打開時出現）
│    要去運動喔，別又鬼混   │
│                         │
│          09:12 起床好累 ▐│  ← 我的話（右邊）
│      12:30 午餐吃了拉麵 ▐│
│ ▌Theo：拉麵又？你這週    │  ← Theo 的回應（左邊）
│  第三次了吧               │
│                         │
├─────────────────────────┤
│ [💬 聽聽 Theo 的想法]     │
│ [🌙 結束今天]             │
├─────────────────────────┤
│ [ 輸入框……        ] 🎤 ➤│  ← 打字或按麥克風
└─────────────────────────┘
```

- 我的話、Theo 的回應、提醒、總結，全部依時間排在同一條聊天裡
- 看以前的日子時，只能看，不能新增內容

### 3.2 目標頁

列出所有目標：未來的、已完成 ✅、沒做到的。可以修改或刪除。
入口：雛形先在聊天頁上方放一個 🎯 按鈕。❓ 看過實際畫面後再決定要不要移到設定頁

### 3.4 日曆頁（點上方的日期打開）

- 一次顯示一個月，可以切換上個月／下個月；星期一開頭
- 有寫日記的日子：黃色小點；有目標的日子：藍色小點；今天有外框
- 點過去的某一天（或今天）→ 回到聊天頁並跳到那一天；未來的日子不能點
- 日曆下方：這個月的回顧（週回顧、月回顧），新的在上面

### 3.3 設定頁

- Theo 的個性：直率吐槽（預設）／溫柔體貼／熱血教練／看情況切換
- AI 金鑰：Groq（主力）、Gemini（備援），各自測試連線
- 匯出備份／匯入備份（下載一個檔案，換手機時用）

## 4. 功能怎麼運作

### 4.1 語音輸入（R2）

- 按 🎤 → 用瀏覽器內建的語音辨識（中文），說完後文字出現在輸入框，可以修改再送出
- ⚠️ **風險**：iPhone Safari 的語音辨識有時不太穩。如果實測不好用，改用 iPhone 鍵盤本身的麥克風（聽寫）功能，這個一定能用
- 不保留錄音檔

### 4.2 「一天」怎麼算

- **一天在凌晨 4 點換日**：半夜 1 點寫的內容，還是算在前一天

### 4.3 Theo 的回應（R5）

按「聽聽 Theo 的想法」→ 把**今天到目前為止的內容**和**個性設定**送給 AI → Theo 回一段話。
Theo 會看完整個今天再回應，而不只是看最後一句。

- AI 會「先思考再回答」：回應比較有深度（2026-10-08 決定，品質優先）
- 主力用 Groq：專用晶片讓思考後的回答也很快
- Groq 失敗（太忙、額度用完、金鑰有問題）時，自動換 Gemini；兩個都失敗才顯示錯誤，並列出各自的原因
- 模型優先用 Qwen（中文強項），不行再換 gpt-oss；App 會自動查詢 Groq 目前有哪些模型
- **不用比較笨的小模型當備援**：寧可告訴對方「太忙了」，也不要給笨的回答
- 等待時顯示「Theo 正在思考……」
- 請 AI 分成 1～3 則短訊息（用空行隔開），App 拆開後一則一則顯示，中間顯示「正在思考……」停頓一下

### 4.4 目標偵測（R7）

需求是「平常只記錄、按了才回」，但目標要即時記下來，所以這裡有一個例外：

- 每次送出後，先在手機上檢查有沒有「明天、週末、禮拜、下週……」這類未來的字眼，**有才**在背景請 AI 判斷「這句有沒有提到未來想做的事」
- 有的話，Theo 跳出一個小確認：「我幫你記：週三下午運動，對嗎？」 [對] [不對]
- **只抓明天以後的事**：當天的行程（例如「等一下去圖書館」）不記，避免一直跳確認
- 已經記下的目標不會重複問
- 說得很明確（一個日期＋時段）：用「我幫你記：……對嗎？」[對][不對]
- 說得比較模糊（例如「這個週末」、沒說時段、用問句）：Theo 改用提問卡片
- 手機自己也會檢查：日記有「週末、有空、改天、下週」這類模糊字眼，就算 AI 只給一個日期，也一律用提問卡片；「週末」一定列出星期六和星期日
  「要幫你記下來嗎？」→ 選哪一天（AI 列出可能的日期）→ 選時段 [早上][中午][下午][晚上][還不確定] → [記下來][不用]
- 沒有的話，什麼都不會發生

### 4.5 提醒（R7）

每次打開 App 時檢查：

| 情況 | Theo 會說 |
|---|---|
| 目標在**明天** | 前一天提醒：「明天下午要去運動喔」 |
| 目標在**今天** | 當天提醒：「今天下午記得運動」 |
| 目標**已經過了** | 追蹤：「上次說要去運動，有去嗎？」 [有！] [沒有…] → 有的話稱讚你 |

每種提醒只說一次，不會一打開就重複講。

- 回答「有／沒有」之後，Theo 會用自己的個性回一句話（AI 連不上時用預設的話）
- 目標頁可以手動新增目標，也可以把目標標成完成，或改回未完成

### 4.6 每日總結（R6）

- 按「結束今天」→ AI 整理出 **今天做了什麼** 和 **今天的亮點**，以 Theo 的語氣出現在聊天最後
- 打開 App 時，如果昨天有寫東西但沒有總結，就自動幫昨天補做，並在今天的聊天最上面通知「我幫你整理好了」
- 同一天可以重新整理，新的總結會取代舊的
- 總結除了「做了什麼」和「亮點」，也附上 Theo 的一句總評

### 4.7 每週／每月回顧（R8）

- 打開 App 時檢查：上一週（星期一～日）、上一個月有寫日記但還沒有回顧，就自動產生
- 為了省額度：有每日總結的日子用總結，沒有的才用原本的日記（太長會截短）
- 內容：做了什麼、亮點、心情走勢、給下週／下個月的小建議，也會參考那段期間的目標
- 產生後，今天的聊天最上面通知「上週的回顧整理好了 [看看]」
- 回顧放在日曆頁下方（見 3.4）

## 5. 資料怎麼存

| 資料 | 內容 |
|---|---|
| 訊息 | 時間、誰說的（我／Theo）、文字、類型（日記／回應／提醒／總結） |
| 目標 | 要做什麼、什麼時候、狀態（未完成／完成／沒做到）、提醒過了沒 |
| 總結 | 存成一則特別的訊息（類型是「總結」），內容有：做了什麼、亮點、Theo 的一句總評 |
| 回顧 | 類型（週／月）、期間、做了什麼、亮點、心情、建議 |
| 設定 | 個性、AI 金鑰 |

⚠️ **iPhone 的限制**：網頁如果**沒有加到主畫面**，Safari 可能在 7 天沒打開後清掉資料。所以一定要加到主畫面，也建議偶爾匯出備份。

## 6. 外觀

- 像聊天 App：我的泡泡在右邊、Theo 的在左邊
- 字要夠大，按鈕要夠大
- 圖示用線條風格的 icon（Lucide），**不用 emoji**
- 主題：**溫暖的黃色**，搭配藍色和橘紅色點綴（之後隨時可以改，顏色統一寫在 `style.css` 最上面）

| 用途 | 顏色 | 色碼 |
|---|---|---|
| 背景 | 奶油白 | `#FFF8E7` |
| 我的泡泡 | 暖黃 | `#FFD966` |
| Theo 的泡泡 | 白 | `#FFFFFF` |
| 主要按鈕、標題 | 深暖黃 | `#F2A900` |
| Theo 的名字、連結 | 藍 | `#3B6EA8` |
| 提醒、重要按鈕 | 橘紅 | `#E8613C` |
| 文字 | 深咖啡 | `#3D3027` |
