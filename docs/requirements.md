# 需求文件

> 狀態：✅ v1.2 已確認（2026-10-08：AI 改成 Groq 主力＋Gemini 備援）

## 一句話說明

一個主要在手機上用的日記，像跟朋友聊天一樣，想到什麼就說；它會回應我、給建議或稱讚，晚上幫我整理一整天做了什麼。

---

## R1. 手機優先

**描述**：我主要用手機寫日記，所以畫面要以手機為主來設計。

**完成標準**：
- [ ] 在手機瀏覽器打開時，不用放大縮小就能舒服地閱讀和輸入
- [ ] 按鈕夠大，單手用拇指就點得到
- [ ] 可以加到手機主畫面，點開就像一個 App
- ✅ 手機：iPhone（Safari）

## R2. 語音輸入

**描述**：我想用講的來寫日記，不想打字。

**完成標準**：
- [ ] 有一個明顯的麥克風按鈕
- [ ] 說完話之後，內容會變成文字出現在輸入框
- [ ] 送出前可以修改辨識錯誤的字
- [ ] 也可以改用打字
- [ ] 只存辨識後的文字，不保留錄音檔

## R3. 一天寫很多次

**描述**：我不是一天只寫一篇，而是每個時段想到就寫一點。

**完成標準**：
- [ ] 每一則都會自動記錄時間
- [ ] 同一天的內容依時間順序排在一起
- [ ] 可以翻看以前的日子

## R4. 聊天模式

**描述**：寫日記的感覺要像跟朋友聊天（「欸我跟你說……」），不是填表格。

**完成標準**：
- [ ] 畫面長得像聊天 App：我說的話在右邊，朋友的回應在左邊
- [ ] 送出後馬上出現在對話裡

## R5. 朋友般的回饋

**描述**：日記會像朋友一樣回應我，除了陪伴和安慰，也會給建議或稱讚。

**完成標準**：
- [ ] 平常只記錄；我按「聽聽你的想法」按鈕時，朋友才回應
- [ ] 回應會依內容調整：難過時安慰、做得好時稱讚、遇到問題時給建議
- [ ] 語氣像朋友，不像客服或老師
- [ ] 預設個性：直率，像好朋友會吐槽、該說的直接說
- [ ] 設定頁可以切換個性（例如：直率吐槽／溫柔體貼／熱血教練／看情況切換）
- [ ] 朋友的名字：**Theo**

## R6. 一天的整理

**描述**：幫我整理今天一整天都做了什麼。

**完成標準**：
- [ ] 根據今天所有的內容，產生一份當日總結
- [ ] 總結會存下來，之後可以回頭看
- [ ] 總結包含兩部分：**今天做了什麼**、**今天的亮點**
- [ ] 可以自己按「結束今天」按鈕產生總結
- [ ] 如果忘了按，隔天打開日記時自動幫昨天補做總結

## R7. 目標與提醒

**描述**：聊天時如果我提到想做的事（例如「我禮拜三下午想去運動」），朋友會記下來，並在前一天提醒我。

**完成標準**：
- [ ] 從聊天內容中認出「目標」，包含要做什麼、什麼時候做
- [ ] 記下目標時跟我確認一下（例如「好，我幫你記：週三下午運動 💪」），避免記錯
- [ ] 可以看到目前所有的目標，也可以修改或刪除
- [ ] 前一天會提醒我（例如「欸，明天下午要不要去運動？」）
- [ ] 事情過了之後，朋友可以問我有沒有做到，做到就稱讚我
- [ ] 雛形階段：打開日記時，朋友主動提起明天的目標
- [ ] 之後搬到雲端時，再加上手機通知（就算沒打開也收得到）
- [ ] 當天打開日記時再提醒一次

---

## 重大決定

- ✅ **AI 回饋怎麼做**：雛形階段用 **Groq** 免費版當主力（又快又會思考，一般不拿資料訓練），Groq 不行時自動換 **Gemini** 免費版當備援；程式要寫成之後可以換成其他 AI
  - 2026-10-08 從 Gemini 換過來，原因：Gemini 免費版常塞車、太慢，塞車時備用的小模型又太笨
- ✅ **資料存在哪裡**：雛形階段先存在手機上；覺得好用再改成雲端同步
